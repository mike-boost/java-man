# Report Outline Checklist

Use this to ensure both documents follow the fixed sections and contain evidence anchors.

## PROJECT_PROFILE.md
- Cover (name, version, date, scope, audience)
- Executive Summary (role, top 10 findings, integration snapshot, readiness score, top 5 actions)
- Reader Guide
- Repository Map & Service Identity
- Functional Role & Capabilities
- System Context & Interactions (integration matrix + contract surfaces)
- Critical Business Flows (3–5 + sequence diagrams)
- Configuration Model & Environment Mapping
- Data Layer (ops-focused)
- Deployment & Kubernetes Readiness
- Observability & Operability
- Testing Overview (reference only)
- Risks, Unknowns, and Deployment Readiness
- Verification Checklist (filled)

## DEPLOYMENT_RUNBOOK.md
- Dependencies & Connectivity
- Build & Package
- Configuration & Secrets
- Local Run (Minimal)
- Kubernetes Deployment Steps
- Post-deploy Validation
- Troubleshooting Playbook (Top 10)
- Rollback Strategy
- Operational Checklists (Go-live / Day-2)
- Monitoring Suggestions
